# 💜 Trade-MBTI: 나에게 딱 맞는 무역 직무 찾기

**Trade-MBTI**는 무역 실무 프로세스와 성향 차이를 기반으로 제작된 20문항의 직무 적합도 테스트 웹 애플리케이션입니다.  
사용자의 업무 스타일을 4대 축으로 분석하여 가장 잘 어울리는 6개 핵심 무역 직무와 매칭하고, 라벤더 테마의 3D 일러스트 결과 카드를 제공합니다.

---

## ✨ 주요 기능

* **20문항 성향 진단:** 실무 기반의 A/B 양자택일형 질문을 통해 4개 성향 축 분석
* **6개 핵심 직무 매칭:** 해외영업, 무역영업관리, 포워딩, 글로벌 소싱, 관세/통관, 해외마케팅 직무 추천
* **라벤더 테마 UI:** 따뜻하고 정돈된 라벤더 파스텔 톤앤매너 적용
* **폰트:** Pretendard-Regular.otf 적용
* **MBTI 스타일 결과 카드:** 4글자 성향 코드, 직무별 맞춤 3D 캐릭터 일러스트, 지표별 진행 바(Progress Bar), 상세 분석 코멘트 제공

---

## 🧭 평가 4대 성향 축

* **F (Front)** 대외 현장 / 영업형 vs **B (Back)** 백오피스 / 관리형
* **A (Action)** 속도 / 임기응변형 vs **P (Plan)** 정확도 / 원칙준수형
* **R (Relationship)** 사람 / 협상 중심 vs **D (Data)** 수치 / 데이터 / 법규 중심
* **C (Create)** 기획 / 시장개척형 vs **O (Operate)** 운영 / 실행안정형

## 🎯 추천 무역 직무 (6개)

| 직무 | 주요 코드 매칭 | 핵심 역량 |
| :--- | :--- | :--- |
| **해외영업 (Overseas Sales)** | `FARC` | 바이어 발굴, 가격 협상, 글로벌 시장 개척 |
| **무역영업관리 (Sales Admin)** | `BPDO` | 수주 후 납기 관리, 수출입 선적 서류 완결, 백오피스 운영 |
| **포워딩/물류운영 (Logistics)** | `BARO` | 물류 스케줄링, 운임 협상, 운송 트러블슈팅 |
| **글로벌 소싱/구매 (Sourcing)** | `BADC` | 공급망 탐색, 원가 분석 및 단가 협상, 리스크 관리 |
| **관세/통관 컴플라이언스 (Compliance)** | `BPDO` | HS Code 분류, FTA 원산지 증명, 무역 법규 및 규정 준수 |
| **해외전시/해외마케팅 (Global Marketing)** | `FARC` | 글로벌 전시 기획, 시장조사, 부스 운영 및 리드 확보 |
